# UNP_ML_CLASSIFICATION_PROJECT_PCOS_DIAGNOSTIC_INDICATORS_USING_PYTHON

I completed this project as part of my Data Science and Machine Learning Internship with United Network of Professionals (UNP), and it was executed as a collaborative group project.

1. Project Overview: The project focused on detecting Polycystic Ovary Syndrome (PCOS) using machine learning classification techniques.

2. Objective: The main objective was to predict whether a patient has PCOS based on clinical, hormonal, physical, and lifestyle-related information.

3. Dataset: We worked with a dataset containing 541 patient records and 45 columns, including age, BMI, hormone levels, menstrual cycle details, and symptoms.

4. Data Preprocessing: We cleaned column names, removed unnecessary columns, converted data types, handled missing values, and corrected invalid blood pressure readings.

5. Data Encoding and Scaling: We applied one-hot encoding to categorical features and StandardScaler for feature scaling.

6. Feature Selection: We performed Variance Inflation Factor (VIF) analysis to identify and reduce multicollinearity among the features.

7. Exploratory Data Analysis: We analysed class distribution, feature distributions, outliers, and relationships between different patient attributes and PCOS.

8. Correlation Analysis: We observed that follicle counts, skin darkening, hair growth, weight gain, and menstrual cycle irregularity showed notable relationships with PCOS.

9. Machine Learning Models: We implemented Logistic Regression, K-Nearest Neighbors, Decision Tree, Random Forest, Support Vector Machine, Gradient Boosting, and Naive Bayes.

10. Model Evaluation: We evaluated model performance using Accuracy, Precision, Recall, F1-score, and ROC-AUC.

11. Train-Test Splitting: We compared model performance across five different train-test ratios: 80-20, 75-25, 70-30, 65-35, and 60-40.

12. Artificial Neural Network: We developed and tested 10 different ANN architectures using TensorFlow, experimenting with different hidden layers, epochs, and Adam and SGD optimizers.

13. Best Model Performance: Random Forest achieved the highest accuracy of 89.86% with the 60-40 split, while Gradient Boosting achieved the highest F1-score of 0.8381 and ROC-AUC of 0.9573.

14. Applications: This project demonstrates how machine learning can support preliminary PCOS risk classification and help identify patterns in clinical and lifestyle data. It is not a substitute for medical diagnosis.

15. Learning Outcome: Through this collaborative project, I gained practical experience in data preprocessing, exploratory data analysis, feature selection, classification algorithms, neural networks, and model evaluation using Python.
